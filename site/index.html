AI change-request assistant for a client portal

Shipped in v0.8.0 · Nov 2026 · behind a feature flag

Clients of BooPixel, my web agency, describe a change to their website in plain Portuguese. A Claude agent scopes it, quotes it and turns it into a payable request for the team, and it can't invent a price or act for the wrong client.

Client chat→ Claude agent→ listar_sites→ orcar_alteracao→ explicit "yes"→ criar_pedido→ Request + charge
Role
Founder. I designed the agent, its tools and safeguards, and integrated it into the product.
Problem
Turn vague, non-technical requests into scoped, priced work without manual back-and-forth.
Model
Claude on Managed Agents, with three custom tools executed by the backend
Status
Merged, released and deployed. The assistant is switched off by a flag until launch.
  • Pricing never comes from the model. The agent only estimates hours, and a deterministic server function computes price, discount and delivery date. The prompt also forbids negotiating.
  • Identity comes from the session, not the prompt. Tools act on the authenticated client of the conversation, and nothing in the model's tool input can choose another client.
  • Tool calls are idempotent. Each call is stored by its tool-use ID under a lock, in the same database transaction as its effect, so a retried or duplicated call can't create a second order.
  • A human confirms before any side effect. The order tool requires the client's own confirmation sentence, which is stored with the request.
  • Defences against prompt injection and runaway cost. The model treats user text as data, sessions have a spend cap, messages are rate-limited per hour, and every tool call is audited.
  • Tests run against a scripted model gateway. The full conversation flow is tested in CI with no live API calls.

Guarded quote agent: open source, with evals

Public code · Nov 2026

An open, generic version of the pattern above that anyone can run and inspect. A Claude agent scopes and quotes work, the server enforces every rule that involves money or identity, and an evaluation suite measures how the model behaves under pressure.

Code
github.com/mateusschoffen/guarded-quote-agent
Architecture
Messages API with a manual tool loop, so the eval harness can swap the model and inspect every tool call
Tests
44 offline tests in CI, no API key needed
  • Evaluation suite: 12 scripted conversations, run several times each, graded deterministically: order created only when it should be, realistic hour estimates, correct site, no invented prices, replies in the client's language (EN/FR/PT), no prompt leak.
  • Adversarial scenarios: discount pressure, fake "admin mode" injection, prompt-leak requests, another client's website, oversized projects.
  • A confirmation the model can't fake: the order needs the client's own words, written after the quote. One confirmation creates at most one order.
  • Guardrail-block metric: counts how often the server had to stop the model. That measures model discipline separately from system safety.
  • Gradio demo with a live panel of every tool call, including the ones the server blocked.
